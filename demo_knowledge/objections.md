# Objection Handling

"We already have a CRM." Acknowledge that the CRM remains the system of record. Position Northstar Revenue OS as a controlled workflow and decision layer that improves consistency before data is written back to existing systems.

"AI decisions are a black box." Explain that every qualification run stores structured inputs, the controlled outcome, latency, and state transitions. Research recommendations also retain the internal knowledge chunks that supported the context.

"Our data is incomplete." Start with the fields the team can trust and route uncertain cases to manual review. Do not present missing data as known. A pilot should measure data completeness and identify which fields materially improve qualification.

"We cannot send data to public research tools." The internal knowledge workflow does not browse the web. It retrieves only approved documents stored in the organization's PostgreSQL knowledge base.
